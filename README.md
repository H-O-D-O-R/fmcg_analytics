# FMCG Analytics

Сервис бизнес-аналитики для анализа продаж, прибыли, товаров, категорий, клиентов, запасов и логистики.

## Возможности

* анализ продаж и выручки;
* анализ прибыли и рентабельности;
* анализ товаров и категорий;
* ABC-анализ;
* анализ клиентов;
* анализ запасов;
* анализ логистики;
* построение графиков и визуализаций.

## Стек

* Python
* PostgreSQL
* SQL
* Pandas
* NumPy
* Matplotlib

## Архитектура

```text
Repository → Service → Analytics / Visualization
```

`repositories` — работа с SQL и базой данных.
`services` — бизнес-логика и подготовка данных.
`analytics` — аналитические расчёты.
`visualization` — построение графиков.
`database` — подключение и схема БД.

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить аналитику:

```bash
python main.py all
```

Сгенерировать графики:

```bash
python main.py sales_images
```

База данных содержит данные FMCG-компании для проведения аналитических исследований.
